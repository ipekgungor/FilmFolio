# FilmFolio
FilmFolio, developed using ASP.NET, HTML, CSS, JS, and API integration, enables users to rate and comment on movies. It also offers access to critic scores via API and provides a recommendation system along with gamification features for an enhanced user experience.

## Technologies Used

- **ASP.NET**: Framework used for building the server-side application and handling business logic.
- **HTML - CSS - JS**: 
- **API Integration**: External APIs for accessing critic scores and movie data.
- **Machine Learning (Python)**: Algorithms used to provide personalized movie recommendations.
- **Gamification**: Features designed to enhance user engagement through rewards and interactive elements.

## Setup

1. **Clone the Repository**:
   - Clone the project repository using Git:
     ```bash
     git clone https://github.com/ipekgungor/FilmFolio.git
     ```

2. **Open in Visual Studio**:
   - Open the project in Visual Studio by opening the `.sln` file.

3. **Build and Run**:
   - Build the project using the build option in Visual Studio.
   - Run the application to test its functionality.
